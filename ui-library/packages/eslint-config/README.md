# @tu-ui/eslint-config — Shared ESLint Configurations

Configuraciones reutilizables de ESLint para garantizar reglas de calidad de código uniformes en todas las aplicaciones y paquetes del monorepo **tu-ui**.

## Descripción

Provee configuraciones preparadas para TypeScript 6.0, React 19 hooks, ordenamiento de imports y detección de malas prácticas en código client-side y server-side.

## Estructura del Proyecto

```
packages/eslint-config/
├── index.js               # Configuración base de ESLint
├── package.json
└── README.md              # Documentación de contexto
```
