# Changelog

All notable changes to this package are recorded here. The Usalyt package set uses the fixed `0.0.1` version group until a deliberate versioning change is approved.

## 0.0.1 — 2026-11-07

### Added

- Initial Usalyt release candidate for `@usalyt/tsconfig`.
- `MIT` license text, package-scoped MIT exception, and source-availability documentation. The five other public packages remain `GPL-3.0-only`.
- Published presets `base.json`, `react.json`, and `next.json`, each exposed through a package subpath.
- External-consumer TypeScript smoke check and automated preset, `extends` target, export, and README checks.
- Package README rewritten in English with the actual supported preset set, usage examples, the retained MIT license, and the recorded provenance status.

### Notes

- This is an initial `0.0.1` release candidate. It is not a stability or compatibility guarantee.
