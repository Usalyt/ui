## Install the CLI

Initialize the project in your Next.js, Vite or Astro app:

```bash
npx @usalyt/cli init
```

`init` creates `usalyt.json` with the component directory and `cn()` utility paths used by the CLI.

## Add Components

Add primitives to your `@/components/ui` folder:

```bash
npx @usalyt/cli add button dialog input tabs
```

Blocks install the same way:

```bash
npx @usalyt/cli add auth-form project-kanban-board
```

`usalyt add` installs every referenced primitive and the shared `cn()` utility automatically, rewrites relative imports for your configured paths, and reports how many items were installed or skipped. If none of the requested components exist in the registry, the command exits with a non-zero status and writes no files.
