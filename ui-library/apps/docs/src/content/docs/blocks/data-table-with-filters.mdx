## Usage

```tsx
// components/ui/data-table-with-filters/data-table-with-filters.tsx
import { DataTableWithFilters, type SystemUser } from "@usalyt/ui";

const users: SystemUser[] = [
  {
    id: "user-01",
    name: "Alex Rivera",
    email: "alex@uxcheck.io",
    role: "Evaluator",
    status: "Active",
  },
];

export function TeamUsersTable() {
  return (
    <DataTableWithFilters
      data={users}
      title="Team directory"
      description="Review project access and filter members by role."
    />
  );
}
```

## Containment

The Block relies on DataTable's local horizontal scrolling; it adds no second overflow container. Wide directory rows scroll inside the table frame while the title and role filter stay in place.
