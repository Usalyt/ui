## Usage

```tsx
// components/ui/dashboard-header/dashboard-header.tsx
import { DashboardHeader } from "@usalyt/ui";

export function AppHeader() {
  return (
    <DashboardHeader
      title="Dashboard"
      userName="Alex Rivera"
      notificationCount={2}
      onSearch={(query) => console.log(query)}
      onNotificationsClick={() => console.log("notifications")}
      onProfileSettings={() => console.log("profile")}
      onTeamManagement={() => console.log("team")}
      onLogout={() => console.log("logout")}
      actions={<InviteButton />}
    />
  );
}
```

## Desktop order

The semantic order is breadcrumb, actions, then search on every breakpoint. The visual order follows that same DOM and tab sequence; desktop CSS no longer moves search ahead of the action group. Custom actions, notification and profile controls keep their existing callbacks and mobile wrapping.
