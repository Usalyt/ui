## Usage

```tsx
// components/ui/blocks/empty-state-block.tsx
import { EmptyStateBlock } from "@usalyt/ui";

export function EvaluationsEmptyState() {
  return (
    <EmptyStateBlock
      title="No heuristic evaluations yet"
      description="Inspect elements on the page or launch the extension to log your first findings."
      actionLabel="Launch Extension"
      secondaryActionLabel="View Docs"
      onAction={() => console.log("launch")}
    />
  );
}
```

## Long actions

Primary and secondary action labels are never truncated. Inside a small container the action group wraps, each button stays within the block, and the full label remains readable and clickable. The existing primary/secondary order, handlers and empty non-action state are unchanged.
