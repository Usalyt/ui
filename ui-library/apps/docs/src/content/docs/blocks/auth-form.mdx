Reference authentication Block composed from Card, Form, Input, and Button. `onSubmit` may return a promise: the action is disabled with `aria-busy` while pending, and a rejected promise renders a `role="alert"` message. The Block never implements authentication itself.

## Usage

```tsx
// components/ui/auth-form/auth-form.tsx
import { AuthForm } from "@usalyt/ui";

export function SignIn() {
  return (
    <AuthForm
      title="Sign In"
      description="Enter your email and password to access your account"
      onSubmit={async (values) => {
        await signIn(values);
      }}
    />
  );
}
```
