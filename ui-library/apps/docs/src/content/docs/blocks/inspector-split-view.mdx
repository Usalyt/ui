## Usage

```tsx
// components/ui/inspector-split-view/inspector-split-view.tsx
import { InspectorSplitView, type DOMNodeItem } from "tu-ui";

const nodes: DOMNodeItem[] = [
  {
    id: "dom-body",
    tag: "body",
    selector: "body.theme-dark",
    classes: "theme-dark antialiased",
    children: [
      {
        id: "dom-btn-checkout",
        tag: "button",
        selector: "button#checkout-btn.btn-primary",
        classes: "btn-primary w-full py-3",
        role: "button",
      },
    ],
  },
];

export function ElementInspector() {
  return (
    <InspectorSplitView
      nodes={nodes}
      defaultSelectedNodeId="dom-btn-checkout"
      onAuditElement={(node) => console.log("audit", node.selector)}
    />
  );
}
```

## Long details

The details pane scrolls vertically inside the fixed-height split view, while the DOM tree keeps its own independent scroll. Long selectors and class lists remain reachable without expanding the page or changing the selected node, tree interaction or detail callbacks.
