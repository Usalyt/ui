## Visión General

**tu-ui** es una biblioteca de primitivas de interfaz headless y accesibles, basadas en **Base UI v1.x** y estilizadas con **Tailwind CSS v4** mediante clases `@theme`.

## Características Clave

- **Headless y accesible**: Implementado sobre Base UI para soporte total WAI-ARIA y navegabilidad por teclado.
- **Tailwind v4 CSS-First**: Tokens `@theme` nativos sin archivos de configuración JavaScript.
- **Multiplataforma**: Compatible con Next.js 15+, React 19+ (Vite) y Astro 7+.
- **Integración con IA**: Incluye servidor MCP (`@tu-ui/mcp-server`) para generación de código asistida.
