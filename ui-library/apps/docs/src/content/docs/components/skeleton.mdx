## Usage

```tsx
// components/ui/skeleton.tsx
import { Skeleton } from "tu-ui";

export function SkeletonExample() {
  return (
    <div className="w-96 space-y-2">
      <Skeleton className="h-4 w-full" />
      <Skeleton className="h-4 w-3/5" />
    </div>
  );
}
```

Skeleton has no intrinsic size. Always give it explicit dimensions (`h-*`/`w-*`) or a parent with a definite width; percentage widths resolve against the caller's container.
