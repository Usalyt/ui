## Layout behavior

`DrawerFooter` applies the compact 8px sibling gap at every breakpoint. Left and right panels remain full height and scroll their content; top and bottom panels are capped to the viewport height minus a 2rem inset and scroll internally. Side placement, state/gesture behavior and caller class overrides remain unchanged.
