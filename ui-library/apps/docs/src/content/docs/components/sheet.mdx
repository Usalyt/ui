## Layout behavior

`SheetFooter` applies the compact 8px sibling gap at every breakpoint while keeping its section spacing. Left and right panels remain full height and scroll their content; top and bottom panels are capped to the viewport height minus a 2rem inset and scroll internally. The mobile Sidebar composition, side placement and caller class overrides remain unchanged.
