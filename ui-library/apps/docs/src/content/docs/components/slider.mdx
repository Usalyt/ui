## Usage

```tsx

import { Slider } from "tu-ui";

export function SliderExample() {
  return <Slider />;
}
```

## Vertical orientation

The existing `orientation="vertical"` prop renders the control as a vertical track; give the slider a height from the caller (`h-64` or `h-full`). The thumb stays 20px, keyboard arrows/Home/End and value callbacks are unchanged. Horizontal remains the default.
