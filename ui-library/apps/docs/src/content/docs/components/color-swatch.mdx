Display-only color reference: a chip painted with the supplied color plus the color value as readable text. Use it in token tables, palette documentation and design-system references — not as a color picker, copy control or form field.

## Usage

```tsx
// components/ui/color-swatch/color-swatch.tsx
import { ColorSwatch } from "tu-ui";

export function TokenValue() {
  return (
    <div className="flex items-center justify-between gap-4">
      <span className="font-mono text-xs text-muted-foreground">
        --color-acid-lime
      </span>
      <ColorSwatch color="#e4f222" />
    </div>
  );
}
```

`color` accepts any valid CSS color string, including hex, `rgb()`, `hsl()`, `oklch()` and theme variables such as `var(--color-acid-lime)`. The string is rendered verbatim, so the visible value always reflects the value you passed.

The value text supplies the color information to assistive technology; the chip itself is hidden from the accessibility tree to avoid a duplicate announcement. The component is a plain `span` with no role, tab stop, pointer affordance or event handler, so it renders statically and does not require client-side hydration.
