Toaster primitive wrapping [`sonner`](https://sonner.emilkowal.dev/) with token-mapped toast styling. Render `<Toaster />` once near the root, then call the re-exported `toast()` from anywhere.

## Usage

```tsx
// components/ui/sonner.tsx
import { Toaster, toast } from "tu-ui";

export function SaveNotice() {
  return (
    <>
      <Toaster position="bottom-right" />
      <button onClick={() => toast("Report exported", { description: "Saved to your downloads folder." })}>
        Export report
      </button>
    </>
  );
}
```
