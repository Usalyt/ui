Step progress primitive. `Stepper` lays out `Step`s with `StepSeparator`s; each `StepIndicator` expresses `active`, `completed`, `inactive`, `error`, or `disabled` state, and `aria-current="step"` marks the active one.

## Usage

```tsx
// components/ui/stepper.tsx
import { Stepper, Step, StepIndicator, StepTitle, StepDescription, StepSeparator } from "tu-ui";

export function SetupFlow() {
  return (
    <Stepper>
      <Step status="completed">
        <StepIndicator status="completed" />
        <div>
          <StepTitle>Scope</StepTitle>
          <StepDescription>Pick the flows to evaluate</StepDescription>
        </div>
      </Step>
      <StepSeparator />
      <Step status="active">
        <StepIndicator status="active" stepNumber={2} />
        <div>
          <StepTitle>Evaluate</StepTitle>
          <StepDescription>Log findings per heuristic</StepDescription>
        </div>
      </Step>
    </Stepper>
  );
}
```
