Star-rating input rendered as a `role="radiogroup"`. Exactly one star is in the tab order, hover previews the value, Arrow keys move selection and focus, Home/End jump to the bounds, and `readOnly` turns the control into a static display.

## Usage

```tsx
// components/ui/rating/rating.tsx
import { Rating } from "tu-ui";

export function SatisfactionRating() {
  return <Rating defaultValue={3} max={5} onChange={(value) => console.log(value)} />;
}
```
