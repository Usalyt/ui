Button primitive that copies a value to the clipboard, flips its icon to a check, and resets itself after a timeout.

## Installation

<Tabs syncKey="package-manager">
  <TabItem label="pnpm">
```bash
pnpm dlx tu-ui add copy-button
```
  </TabItem>
  <TabItem label="npx">
```bash
npx tu-ui add copy-button
```
  </TabItem>
  <TabItem label="bunx">

```bash
bunx tu-ui add copy-button
```
  </TabItem>
</Tabs>

## Usage

```tsx
// components/ui/copy-button.tsx
import { CopyButton } from "tu-ui";

export function CommandCopy() {
  return <CopyButton value="pnpm dlx tu-ui add copy-button" />;
}
```
