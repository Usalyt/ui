## Stacking

Toasts beyond `ToastProvider`'s `limit` (default `3`) stay mounted and inert so they can be promoted when a visible toast closes. Limited entries are removed from the viewport's layout flow, so the stack keeps its bottom-right anchor and only the visible toasts occupy space. Configure visibility and duration with the provider's existing `limit` and `timeout` props.
