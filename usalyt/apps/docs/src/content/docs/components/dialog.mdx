## Usage

```tsx
// components/ui/dialog.tsx
import { Dialog, DialogTrigger, DialogContent, DialogTitle, DialogDescription } from "@usalyt/ui";

export function DialogExample() {
  return (
    <Dialog>
      <DialogTrigger>Open</DialogTrigger>
      <DialogContent>
        <DialogTitle>Modal Title</DialogTitle>
        <DialogDescription>Modal content description.</DialogDescription>
      </DialogContent>
    </Dialog>
  );
}
```

## Layout behavior

Centered dialogs are capped to the viewport height with a 2rem inset and scroll their content, so long forms and short or zoomed viewports keep the title, actions and close control reachable. `DialogFooter` applies a compact 8px gap at every breakpoint: actions stack in reverse DOM order on mobile and become a right-aligned row from `sm`. Caller `className` overrides still apply.
