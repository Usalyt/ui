## Overview

**Usalyt** is a library of accessible headless UI primitives built on **Base UI v1.x** and styled with **Tailwind CSS v4** through `@theme` classes.

## Key Features

- **Headless & Accessible**: Implemented on top of Base UI for full WAI-ARIA support and keyboard navigation.
- **Tailwind v4 CSS-First**: Native `@theme` tokens with no JavaScript configuration files.
- **Cross-Framework**: Compatible with Next.js 15+, React 19+ (Vite), and Astro 7+.
- **AI Integration**: Ships an MCP server (`@usalyt/mcp-server`) for assisted code generation.
