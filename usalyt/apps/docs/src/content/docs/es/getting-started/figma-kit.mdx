## Visión General

El kit de diseño de **Usalyt** en Figma se mapea 1:1 con los tokens de diseño `@theme` de Tailwind v4 declarados en `packages/ui/styles/globals.css`. La hoja de estilos es la fuente de verdad: la biblioteca de Figma refleja sus valores para que el diseño y la implementación se mantengan consistentes.

## Tokens de Color (Paleta Hex)

La paleta se define como valores hexadecimales en el bloque `@theme`. Cada token tiene una variable de Figma con el mismo nombre.

## Radios de Borde

| Variable de Figma | Variable de Tailwind v4 | Valor |
| --- | --- | --- |
| `radius/xs` | `--radius-xs` | `2px` |
| `radius/sm` | `--radius-sm` | `4px` |
| `radius/md` | `--radius-md` | `6px` |
| `radius/lg` | `--radius-lg` | `12px` |
| `radius/full` | `--radius-full` | `9999px` |

## Mantener la Sincronía

1. En Figma, abre el panel de **Local Variables** del kit de Usalyt.
2. Cuando cambie un token, aplica el mismo cambio a la variable `@theme` correspondiente en `packages/ui/styles/globals.css` (o al revés, manteniendo un lado como fuente).
3. El `@usalyt/cli` lee los valores de `@theme`, de modo que los componentes generados con `npx @usalyt/cli add` consumen automáticamente los tokens actualizados.
