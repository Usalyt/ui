# Changelog

All notable changes to this package are recorded here. The Usalyt package set uses the fixed `0.0.1` version group until a deliberate versioning change is approved.

## 0.0.1 — 2026-11-07

### Added

- Initial Usalyt release candidate for `@usalyt/eslint-config`.
- `GPL-3.0-only` license text and source-availability documentation.
- Explicit ESM entry (`index.mjs`) and valid CommonJS entry (`index.js`) that export the same flat config array.
- External-consumer ESLint smoke check and automated entry-parity, consumer-import, manifest, and lint-behavior checks.
- Package README rewritten in English with installation, entry points, rule behavior, license, and source-availability documentation.

### Notes

- This is an initial `0.0.1` release candidate. It is not a stability or compatibility guarantee.
